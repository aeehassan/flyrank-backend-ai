### Presentation project
This project is about creating a compelling presentation on the topic of Machine Learning Algorithms. The diligence statement is:
This presentation on machine learning algorithms was made with Claude AI, chosen because it is this course’s case study and drafts clear writing well. Since my audience is beginner ML students, I want to be clear about where AI contributed.

I divided the project into subtasks and decided how much to delegate. Claude drafted the slide outline, content, and color system, and I approved or changed each choice. It produced the diagrams and proofread the text with less direction, and I cross-checked the results. I first planned to build the deck in PowerPoint, then switched to interactive HTML slides, so Claude built the deck, including dark mode and animations, after I approved each plan. I did the final visual polish myself.

I shared only task details, so no sensitive information was exposed. Ethically, I used diagrams that are common in the field.

To check accuracy, I compared each algorithm’s definition with reliable ML sources through Google. To check appropriateness, I put myself in a beginner’s position and confirmed the language was easy to follow.

I take responsibility for the final output: I reviewed every slide, approved every AI-generated element, and I am accountable for any remaining errors.
